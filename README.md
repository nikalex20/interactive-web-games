# 🎮 Web Mini Games Collection (GSSoC Showcase)

A collection of 5 interactive browser games built with Vanilla JavaScript, HTML5, and CSS3, contributed and merged during **GirlScript Summer of Code (GSSoC)** into [`dhairyagothi/100_days_100_web_project`](https://github.com/dhairyagothi/100_days_100_web_project).
